# SlyNet Radio

Бесплатное интернет-радио со всего мира: жанры, страны, подборки по настроению, избранное, таймер сна, будильник.

- Каталог станций: открытый [Radio Browser](https://www.radio-browser.info/) (без ключа).
- Сайт публикуется автоматически на GitHub Pages при каждом изменении в ветке `main`.
- Работает как приложение: iPhone/iPad — Safari → «Поделиться» → «На экран Домой»; Android — Chrome → «Установить приложение».

## Как менять контент сайта (логотип, тексты, ссылки, свои станции, камеры, ТВ)
1. Откройте сайт с `#admin` в конце адреса — появится Админ-панель.
2. Внесите правки и нажмите «Скачать content.json».
3. В репозитории откройте папку `public` → `Add file` → `Upload files`, загрузите `content.json` с заменой → `Commit changes`.
4. Через 1–2 минуты изменения увидят все посетители.

## Разработка
```
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка типов + сборка в dist/
```
