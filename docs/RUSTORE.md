# SlyNet Radio в RuStore — карточка и сборка

## Сборка
- Пакет: **com.slynet.radio.rustore** (отдельно от APK с сайта `com.slynet.radio`; изменить нельзя).
- Собрать: GitHub → Actions → **Android RuStore** → Run workflow. Файл: Releases → `rustore-latest` → `SlyNetRadio-RuStore.apk`.
- Версия = последняя из `public/releases.json`, код версии = 100 + номер сборки (растёт сам).
- Отличия версии RuStore (метка `SlyNet-RuStore`, код в `src/utils/platform.ts`):
  - ТВ есть, но без каналов РФ и Украины, без новостных, религиозных, парламентских (и по названию: news/новости/…), без «официальных эфиров» новостей.
  - Выключить ТВ только в RuStore: Админка → Видимость → «📺 Телеканалы — в приложении RuStore» → Опубликовать.
  - Нет раздела «Mobile Apps» и баннера «новый APK», нет автообновления кода — обновления только новой версией в RuStore.
- Google Play / App Store (метка `SlyNet-Store`): раздела ТВ нет вообще.

SlyNet Radio — это каталог публичных интернет-трансляций. Звук и видео воспроизводятся напрямую с серверов вещателей, приложение не хранит и не ретранслирует контент.

**Комментарий для модератора:**

Приложение — каталог публичных интернет-радиостанций, телеканалов и веб-камер. Регистрация не требуется (вход по желанию — только для синхронизации избранного), данные для входа не нужны. Аудио и видео воспроизводятся напрямую с официальных серверов вещателей; приложение контент не хранит и не ретранслирует. Телеканалы — только открытые бесплатные трансляции, которые каналы сами публично распространяют; российские, украинские, новостные и религиозные каналы в этой версии исключены. Правообладатель может запросить удаление станции или канала — удаляем в течение 72 часов.
Разрешения: FOREGROUND_SERVICE / MEDIA_PLAYBACK и WAKE_LOCK — воспроизведение радио в фоне; POST_NOTIFICATIONS — плеер в шторке; SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM и RECEIVE_BOOT_COMPLETED — функция «Радиобудильник» (будильник срабатывает точно в заданное время и восстанавливается после перезагрузки).
