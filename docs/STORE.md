Этот файл — памятка к публикации приложений. Отмечено, что уже сделано в коде.

## Уже сделано
- [x] **Политика конфиденциальности** — `public/privacy.html` (ссылка: `https://tenyls.github.io/slynet-radio/privacy.html`). Обязательна в обоих магазинах.
- [x] Нет регистрации, рекламы, аналитики, трекинга → в анкетах «Data safety» (Google) и «App Privacy» (Apple) ответ: **данные не собираются**.
- [x] Нет аккаунтов → требование «удаление аккаунта» не применяется.
- [x] Шрифты встроены в приложение (нет запросов к Google Fonts — GDPR).
- [x] Фильтр станций 18+ (по названию и тегам) — для возрастного рейтинга 12+/Teen.
- [x] Функция «Запись эфира» **автоматически скрыта в приложениях** (Apple 5.2.3, Google Play: нельзя сохранять чужие трансляции). На сайте остаётся.
- [x] Телеканалы — только открытые трансляции с официальных серверов/CDN телеканалов; YouTube — только ссылкой (встраивать нельзя).
- [x] Указаны источники и правообладатели (подвал сайта, политика, раздел ТВ). Есть порядок удаления по запросу правообладателя (72 часа).
- [x] Фоновое воспроизведение и управление с экрана блокировки (Media Session).

- [ ] Скриншоты: телефон 6.7" и 6.5" (Apple), телефон + 7" и 10" планшет (Google). Иконка 1024×1024 без прозрачности (Apple), 512×512 (Google), баннер 1024×500 (Google).

## Что будет в нативных приложениях (следующий этап, Capacitor)
- Фоновое аудио (iOS: `UIBackgroundModes: audio`), управление в «Пункте управления» и на экране блокировки.
- Без http-ограничения: в приложении доступны и http-потоки (ATS-исключение только для аудио).
- `NSMicrophoneUsageDescription` / `NSSpeechRecognitionUsageDescription` — для голосового поиска (текст: «Микрофон нужен только для голосового поиска станций»).
- Apple 4.2 «минимальная функциональность»: приложение не должно быть просто сайтом в рамке — у нас нативный плеер, фон, экран блокировки, избранное офлайн, CarPlay/Android Auto (желательно).

## Тексты для анкет
- **Категория:** Музыка (Apple: Music; Google: Music & Audio).
- **Возраст:** 12+ (Apple) / Teen (Google) — эфир радио не модерируется вживую.
- **Описание (кратко):** «Тысячи бесплатных радиостанций со всего мира: жанры, страны, станции любимых исполнителей, подборки по настроению, таймер сна и будильник. Без рекламы и регистрации.»
- **Права на контент:** «Приложение — каталог публичных интернет-радиостанций. Аудио воспроизводится напрямую с серверов вещателей; приложение не хранит и не ретранслирует контент. Каталог: Radio Browser (открытая база), laut.fm.»
- **Риск Apple 5.2.3:** Apple может спросить права на трансляции. Ответ: мы не транслируем, а только открываем публичные потоки, которые станции сами распространяют для любых плееров (как TuneIn, radio.net, Radio Garden).
